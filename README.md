## 📋 نظرة عامة

نظام مَسَار للمدارس هو نظام إدارة مدرسية شامل ومتكامل مبني بتقنيات حديثة (ASP.NET Core MVC) مع دعم كامل للغة العربية واتجاه RTL. يوفر النظام حلولاً ذكية لإدارة جميع جوانب العملية التعليمية.

### 🤖 تقنيات متقدمة
- **ذكاء اصطناعي مدمج:** محرك تحليل المخاطر والمساعد الذكي
- **التكامل الحكومي:** التوافق مع هيئة الزكاة ZATCA ونظام نور Noor
- **تتبع GPS:** نظام متابعة الحافلات المدرسية لحظياً
- **SignalR:** اتصال حي للدردشة والإشعارات
- **Multi-Tenant:** دعم المؤسسات المتعددة

## 🛠️ التقنيات المستخدمة

- **Framework:** ASP.NET Core MVC (.NET 10.0)
- **Database:** SQL Server
- **ORM:** Entity Framework Core 10.0
- **Authentication:** ASP.NET Core Identity
- **Real-time:** SignalR
- **Background Jobs:** Hangfire
- **Frontend:** Bootstrap RTL + Alpine.js
- **AI Engine:** مدمج ومخصص

### التثبيت والتشغيل

1. **استنساخ المشروع:**
```bash
git clone <repository-url>
cd "MASAR SCHOOL"
```

2. **استعادة الحزم:**
```bash
dotnet restore
```

3. **إعداد قاعدة البيانات:**
```bash
cd Masar.Schools.ERP.WebUI
dotnet ef database update
```

4. **تشغيل التطبيق:**
```bash
dotnet run
```
